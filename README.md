# DEMOS — Telegram Mini App (v0)

Первая кликабельная версия на тестовых данных, без сервера.

- `index.html` — собранное приложение (его отдаёт GitHub Pages и открывает бот).
- `src/` — исходники: `styles.css`, `data.js`, `art.js`, `app.js`.
- `python3 build.py` — пересобрать (пишет в `dist/`; затем скопировать `dist/index.html` в корень).
